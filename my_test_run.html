CHK-002 CRITICAL

Default Credentials Accepted

Platform: PenTera
Host: 10.0.5.50
URL: https://10.0.5.50:8443
The PenTera platform accepted default credentials (admin / changeme). An insider with knowledge of common default passwords can access all pentest results including harvested credentials and attack paths.

Technical Evidence & Proof of Concept

POST https://10.0.5.50:8443/api/login with admin / changeme → 200 OK (authenticated)

🛡️ Remediation Plan

Change all default credentials immediately. Implement a password policy requiring minimum 16 characters. Enable account lockout after 5 failed attempts.

MITRE ATT&CK T1078.001 — Valid Accounts: Default Accounts
NIST SP 800-53 IA-5 (Authenticator Management)
CHK-003 HIGH

Multi-Factor Authentication Not Enforced

Platform: PenTera
Host: 10.0.5.50
URL: https://10.0.5.50:8443
The PenTera login page does not enforce multi-factor authentication. An insider who obtains or guesses valid credentials can access all pentest results without additional verification.

Technical Evidence & Proof of Concept

Login page at https://10.0.5.50:8443/login shows no MFA prompt or TOTP field

🛡️ Remediation Plan

Enable MFA for all accounts. Prefer hardware tokens (FIDO2/YubiKey) or TOTP authenticator apps. SMS-based MFA is better than nothing but vulnerable to SIM swapping.

MITRE ATT&CK T1078 — Valid Accounts
NIST SP 800-53 IA-2(1) (Multi-Factor Authentication to Privileged Accounts)
CHK-004 CRITICAL

API Endpoints Accessible Without Authentication

Platform: PenTera
Host: 10.0.5.50
URL: https://10.0.5.50:8443
The PenTera REST API at https://10.0.5.50:8443/api returned scan data without requiring an API key or authentication token. An insider can programmatically extract all credentials and attack paths.

Technical Evidence & Proof of Concept

GET https://10.0.5.50:8443/api/scans → 200 OK (returned JSON with scan data)
GET https://10.0.5.50:8443/api/credentials → 200 OK (returned harvested credentials)

🛡️ Remediation Plan

Require API key or OAuth token for all API endpoints. Implement rate limiting. Log all API access with source IP and account identity.

MITRE ATT&CK T1106 — Native API
NIST SP 800-53 AC-3 (Access Enforcement), SC-8 (Transmission Confidentiality)
CHK-005 HIGH

Pentest Reports Found on Accessible File Shares

Platform: PenTera
Host: 10.0.5.50

CHK-006 HIGH

Platform Likely Whitelisted in UEBA/NTA — Monitoring Blind Spot

Platform: PenTera
Host: 10.0.5.50
URL: https://10.0.5.50:8443
The PenTera platform at 10.0.5.50 is likely whitelisted in UEBA/NTA exclusion lists to prevent false positives during scheduled scans. If this whitelist is permanent, any insider activity targeting the platform (accessing results, downloading reports) will be invisible to AI-based detection.

Technical Evidence & Proof of Concept

Platform IP 10.0.5.50 identified as active pentest tool. Standard practice is to whitelist during scans. Check UEBA exclusion lists for this IP and associated service accounts.

🛡️ Remediation Plan

Time-box UEBA/NTA whitelists: automate entries to activate only during scheduled scan windows and expire immediately after. Between scans, all pentest platform traffic should be monitored. Create a manual alert rule for any access outside authorized users.

MITRE ATT&CK T1562.001 — Impair Defenses: Disable or Modify Tools
NIST SP 800-53 SI-4 (System Monitoring), AU-6 (Audit Record Review)
CHK-007 MEDIUM

Weak Session Management Detected

Platform: PenTera
Host: 10.0.5.50
URL: https://10.0.5.50:8443
The PenTera dashboard session does not appear to enforce automatic timeout. Sessions may remain active indefinitely, increasing the risk of session hijacking by insiders.

Technical Evidence & Proof of Concept

Session cookie from https://10.0.5.50:8443 lacks 'Max-Age' or 'Expires' attributes. No idle timeout detected after 30-minute test.

🛡️ Remediation Plan

Configure session timeout to 15 minutes of inactivity. Set cookie attributes: Secure, HttpOnly, SameSite=Strict. Implement server-side session invalidation on logout.

MITRE ATT&CK T1539 — Steal Web Session Cookie
NIST SP 800-53 AC-12 (Session Termination), SC-23 (Session Authenticity)
CHK-008 HIGH

Harvested Credentials Stored — Rotation Policy Missing

Platform: PenTera
Host: 10.0.5.50
URL: https://10.0.5.50:8443
The PenTera platform stores credentials harvested during automated pentest scans (NTLM hashes, Kerberos tickets, plaintext passwords, API tokens). If these are not rotated after each engagement, an insider who accesses the results has working credentials for lateral movement.

Technical Evidence & Proof of Concept

Platform type: Autonomous Pentest Tool (stores harvested credentials by design)
Credential rotation policy: Not detected / Unknown
Encryption at rest: Unknown — manual verification required

🛡️ Remediation Plan

Implement mandatory credential rotation after every pentest engagement. Force-reset all credentials discovered by the platform. Ensure credential data is encrypted at rest (AES-256 minimum). Set auto-purge policies to delete harvested credentials after 30 days.

MITRE ATT&CK T1552 — Unsecured Credentials
NIST SP 800-53 IA-5 (Authenticator Management), SC-28 (Protection of Information at Rest)
